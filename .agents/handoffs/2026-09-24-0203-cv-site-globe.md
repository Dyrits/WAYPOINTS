## Globe model (settled after many iterations, do not revert)

- One stop per work experience, chronological, `from: 'YYYY-MM'` drives order and timing.
- Red dot = job location. Blue dot = place worked from when remote (`remoteFrom`: one `['Lieu, Pays', lon, lat]` or a list; `remoteRoute: true` means ordered itinerary → arrows `→`, else `·`; the string `'sur place'` inside the list marks on-site time). Blue dashed animated line from each blue dot to the job.
- Training stops: `type: 'formation'`, no `coords` = online; only their `remoteFrom` places show, as yellow dots, only while that stop is active. Card line "À distance depuis" in yellow.
- Red route line between stops exists but is off: `SHOW_ROUTE = false` in `app.js` (user wanted to see it without; solid, not dotted, if re-enabled).
- Only the active stop and its origins are labelled (collision-skipped); hover shows names.
- Click a dot: one mission → instant jump (`behavior: 'instant'`, no replay of intermediate stops). Several missions on overlapping dots → `#pick-menu` listing them.
- Drag rotates the globe with inertia; eases back on next scroll.
- Card: `remote: true` on an entry adds a blue "À distance" badge; `context: '…'` adds a neutral badge (used for "Visa vacances-travail"). Skill tags on cards were removed on request. "En parallèle" block auto-lists entries still running (parsed from French `dates` text; ends in the stop's start month are excluded).
- Hero coordinates come from `PROFILE.coords`, not the last stop.
